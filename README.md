## 🔬 Selected Projects

### 🧑‍⚖️ Credit Scoring Model
- Built an end-to-end risk engine that ingests messy financial histories and produces decisions people can actually understand.
- Wrapped it behind a clean API and lightweight console so product and risk teams can explore, audit, and iterate.
- Baked in checks for stability, drift, and fairness to keep decisions steady as data changes.

### 🐻 OskiBot (RAG for Campus Info)
- Turned scattered PDFs and web pages into a conversational guide that answers “how do I…?” questions with citations.
- Designed the retrieval flow and memory so it handles follow-ups naturally and stays grounded to source material.
- Piloted with students, tightened prompts and evaluations, and focused on clear, friendly answers over flashy tricks.

### 🧩 RideGrid
- Crafted a network of small services that shuttle events between parts of a marketplace without losing their way.
- Added safe-release patterns and “what’s happening right now?” visibility so on-call feels calmer and fixes come faster.
- Tuned the flow to stay responsive during spikes, prioritizing real-world smoothness over theoretical peak numbers.

### 💳 Personal Finance LLM Tool
- Built a local, privacy-respecting companion that reads filings and personal statements to surface what actually matters.
- Helps people see where money goes, spot habits, and plan ahead with visual explanations instead of dense tables.
- Organized a retrieval layer so every answer can be traced and double-checked when decisions count.

### 🕹️ WhatsApp Image Entity Classifier
- Reframed a spam idea into a visual helper that simply answers “what’s in this picture?” for common entities like people, pets, and objects.
- Focused on lightweight models and practical labeling so it runs smoothly on everyday hardware.
- Shipped a tiny test bench so anyone can drop in photos, try it, and improve the model loop by loop.
